# Limewood Engineering App v5.5

Interactive valve records built from v5.4.3.

- Keeps the physical valve numbering used on plant-room labels.
- Plant-room cards remain unchanged.
- Valve list uses large tap-friendly cards.
- Selecting a valve opens its function, service, type, size, normal position, location, linked asset, verification date and notes.
- Previous/next navigation for valve inspections.
- Valve QR generation and direct QR deep links.
- CSV and XLSX import retained.
