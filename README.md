# Lime Wood Engineering v5.5.1

Patch built from v5.5.

## Changes
- Plant rooms created from the Valve Register are added to the shared master plant-room list.
- New rooms immediately appear in the left navigation, plant-room hubs, Valve Register, PPM and asset selectors.
- Duplicate room names are blocked case-insensitively.
- The Plant Rooms section in the left menu is collapsed by default and opens only when selected.
- Existing interactive valve records, CSV/XLSX import and QR features are retained.
