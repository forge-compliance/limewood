LIMEWOOD ENGINEERING - MAINTENANCE CENTRE REBUILD
Date: 07 August 2026

The maintenance-dashboard.html page has been rebuilt to use the live secured schema:
- public.maintenance_records
- public.maintenance_files
- public.assets
- public.plant_rooms
- private Supabase Storage bucket: asset-files

Removed dependency from the Maintenance Centre on the legacy/non-existent tables:
- maintenance_issues
- maintenance_engineers

Features:
- Asset-linked maintenance records
- Work date and work type
- Engineer/contractor name
- Description, findings and actions taken
- Follow-up flag and follow-up date
- Multiple photo/document attachments
- Private signed attachment links
- Attachment deletion with storage cleanup
- Maintenance record deletion with attachment cleanup
- Viewer read-only UI
- Engineer/admin create, edit, upload and delete UI
- Search and filters
- Dashboard metrics
- CSV export
- Responsive mobile layout

Database/storage security is enforced by the Supabase RLS and storage policies configured separately.
