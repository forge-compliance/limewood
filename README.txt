LIME WOOD MOBILE ENGINEERING APP

WHAT IT IS
A mobile-first offline-capable web app for Android, iPhone, tablets and laptops.

FEATURES
- Search all 26 assets
- Filter by equipment type
- View manufacturer, model and serial number
- View condition, criticality and service information
- Download linked Word/Excel technical documents
- Add temporary notes stored on the device
- Install to the home screen when hosted over HTTPS

HOW TO USE
Option 1: Host the folder on GitHub Pages, Netlify or another HTTPS web host.
Option 2: Run a small local web server from the folder.

IMPORTANT
Browsers normally block app data when index.html is opened directly as a file.
The folder should be served through a web server.

QUICK LOCAL TEST ON WINDOWS
1. Install Python.
2. Open Command Prompt in this folder.
3. Run: python -m http.server 8080
4. On the same device open: http://localhost:8080

INSTALL ON PHONE
- Android Chrome: open the hosted site, then choose Install app / Add to Home screen.
- iPhone Safari: open the hosted site, Share, then Add to Home Screen.
